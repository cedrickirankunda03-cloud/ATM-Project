# ATM Project

## Overview
This project is an educational Automated Teller Machine (ATM) simulation developed in C++.

## Objectives
- Practice object-oriented programming in C++.
- Implement basic ATM operations.
- Validate user input and handle errors.
- Test the program using automated unit tests.
- Maintain clear project documentation.

## Planned Features
- PIN authentication.
- Balance inquiry.
- Cash deposits and withdrawals.
- Transaction history.
- Input validation.
- Savings Goal Tracker (proposed).
- Smart Withdrawal Planner (proposed).

Additional features, including money transfers, will depend on the teacher's requirements.

## Project Structure
- `src/` — C++ source code.
- `include/` — Header files.
- `tests/` — Automated tests.
- `docs/` — Project documentation.
- `requirements.md` — Project requirements.

## Technologies
- C++
- CMake
- Automated unit testing
- Markdown and Doxygen documentation

## Project Status
**Current stage:** Planning and documentation.

Implementation and testing results will be added as development progresses.

## Important Note
This project is an educational simulation. It is not intended for real banking transactions.
