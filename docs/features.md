# ATM Project — Features

## 1. Account Access
- Validate the account PIN.
- Allow access only after successful authentication.

## 2. Balance Inquiry
- Display the current account balance.

## 3. Cash Withdrawal
- Allow users to withdraw money.
- Prevent withdrawals exceeding the available balance.

## 4. Cash Deposit
- Allow users to deposit money.
- Validate the deposit amount.

## 5. Money Transfer
- Transfer money between accounts, if included in the final requirements.
- Validate the transfer amount and account details.

## 6. Transaction History
- Record deposits, withdrawals, and transfers.

## 7. Input Validation
- Reject invalid menu choices and invalid amounts.
- Display clear error messages.

## 8. Testing and Documentation
- Test the main operations.
- Document the program and its features.

- ## 9. Innovative Features

### Savings Goal Tracker
- Allow users to define a savings target.
- Display progress toward the target.
- Update progress when deposits are made.

### Smart Withdrawal Planner
- Suggest a combination of available banknotes for a requested withdrawal.
- Check whether the requested amount can be dispensed.
- Display a helpful message if the amount cannot be provided.
